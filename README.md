# LearnUp

LearnUp is a frontend-only learning management platform built with React and Vite.
This first version focuses on the student experience while keeping the role-based
auth flow ready for Admin, Instructor, and Student.

## Stack

- React
- Vite
- React Router
- HTML
- CSS
- JavaScript
- localStorage for fake authentication

## Included flows

- Role selection
- Login
- Create account
- Forgot password
- Verify email
- Reset password
- Student dashboard
- My courses
- Course details
- Announcements
- Attendance
- Notifications
- Profile
- Ask LearnBot UI
